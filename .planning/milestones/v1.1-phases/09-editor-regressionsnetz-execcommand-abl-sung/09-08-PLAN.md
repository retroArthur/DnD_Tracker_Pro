<objective>
Dritte Migrationsstufe: Alle Einfüge-Operationen des Editors — drei im Zwischenablage-Pfad, eine beim Tabelleneinfügen, eine beim Zeilenumbruch — werden auf Selection/Range-DOM-Operationen umgestellt.

Purpose: Dies ist die sicherheitsrelevanteste Gruppe der Phase, weil hier Fremd-HTML in das Editor-DOM gelangt. Es gilt unverändert D-02 (identisches Markup), D-06 (kein Laufzeit-Rückfall auf die alte API) und die Netz-Freeze-Regel aus D-04a. Der Ersatz nutzt bewusst eine Range-eigene Parse-Funktion, die Skript-Inhalte nicht ausführt, und lässt die vorhandene Bereinigung vor dem Einfügen sowie die Whitelist beim Speichern unangetastet.
Output: migrierte Einfüge-Pfade plus drei wiederverwendbare Hilfsfunktionen, zwei atomare Commits.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Zwischenablage → Bereinigung → Editor-DOM | Fremd-HTML passiert die Attribut-Bereinigung und wird ins Editor-DOM eingefügt |
| Editor-DOM → Persistenz | Eingefügtes Markup passiert die Whitelist beim Speichern |
| Selbst erzeugte Tabellenzeichenkette → Editor-DOM | Anwendungseigenes HTML wird über denselben Einfügeweg eingesetzt |
